## Протоколы взаимодействия

Протокол 1. Взаимодействие Views и Services.
Участники: Views, Services.
Назначение: шифрование и расшифровка персональных данных.
Способ взаимодействия: прямой вызов статических методов класса DataEncryption.
Используемые методы: Encrypt(string) и Decrypt(byte[]).
Формат данных: строка и byte[].
Ограничение: работает только на том же компьютере и под тем же пользователем,
так как используется ProtectedData с областью CurrentUser.

Протокол 2. Хранение сессии пользователя.
Участники: Views, Services, Entities.
Назначение: хранение текущего авторизованного пользователя.
Способ взаимодействия: обращение к статическому свойству UserSession.CurrentUser.
Формат данных: объект Users из модуля Entities.
Ограничение: хранит только одного пользователя за раз; при выходе обнуляется.

Протокол 3. Доступ к базе данных.
Участники: Views, Entities, База данных.
Назначение: чтение и запись данных в SQL Server.
Способ взаимодействия: создание контекста Messenger_Vasanov_ISP33Entities5
и работа через LINQ-запросы.
Формат данных: объекты C#.
Ограничение: строка подключения задаётся в App.config.

Протокол 4. Навигация между страницами.
Участники: Views.
Назначение: переход между страницами приложения.
Способ взаимодействия: вызов Frame.Navigate(Page) и метода MainWindow.NavigateToMainApp().
Формат данных: объект Page.
Ограничение: все страницы наследуются от Page, главное окно - от Window;
стандартная панель навигации скрыта через NavigationUIVisibility="Hidden".

Протокол 5. Использование стилей.
Участники: Views, Styles.
Назначение: единое оформление интерфейса.
Способ взаимодействия: ссылки на XAML-ресурсы через {StaticResource}.
Формат данных: XAML (Style, ControlTemplate).
Ограничение: ресурс должен существовать в App.xaml.
