# Messenger_Vasanov_ISP33

Мессенджер на WPF с авторизацией по номеру телефона, защитой от ботов через капчу, подтверждением по СМС-коду, списком чатов и профилем пользователя. Данные пользователей шифруются, работа с БД через Entity Framework 6.

## Демонстрация

Приложение включает три основных экрана:

- **Вход / Регистрация** - ввод номера телефона, проверка капчи, подтверждение по СМС-коду.
- **Чаты** - список диалогов, поиск пользователя по номеру, отправка сообщений, блокировка собеседника.
- **Профиль** - просмотр и редактирование ФИО пользователя.

## Установка

1. Клонируйте репозиторий: `git clone https://github.com/PRODELKIN/Vasanov_Maksim_LR1.git`
2. Откройте файл решения `Messenger_Vasanov_ISP33.sln` в Microsoft Visual Studio.
3. Восстановите NuGet-пакеты: проект использует **EntityFramework 6.2.0** и **EntityFramework.ru 6.2.0**.
4. Настройте строку подключения к базе данных в файле `App.config` - укажите свой сервер SQL Server и имя базы.
5. Соберите решение и запустите приложение.

## Использование

1. Запустите приложение - откроется страница входа.
2. Введите номер телефона в формате `+7-XXX-XXX-XX-XX`.
3. Введите код капчи и нажмите **«Получить код СМС»**.
4. Введите 4-значный код из всплывающего сообщения.
5. При первом входе пользователь автоматически регистрируется.
6. Перейдите в раздел **«Профиль»**, чтобы заполнить фамилию, имя и отчество.
7. В разделе **«Чаты»** введите номер телефона другого пользователя и нажмите **«+»**, чтобы начать диалог.

**Назначение основных каталогов:**

- **Views** - представление: все страницы и окна приложения, обработка пользовательского ввода.
- **Services** - вспомогательная логика: шифрование персональных данных (`DataEncryption`), хранение текущего пользователя (`UserSession`).
- **Entities** - модель данных: сущности `Users`, `Chats`, `Messages`.

## Данные

Приложение использует базу данных **SQL Server**. Строка подключения настраивается в `App.config`. Основные таблицы:

- **Users** - пользователи (номер телефона, зашифрованные ФИО).
- **Chats** - диалоги между пользователями, статусы блокировки.
- **Messages** - сообщения в чатах.

Персональные данные (ФИО) шифруются средствами `ProtectedData`.
